# Vuls

Vuls is a Telegram-first AI Product Builder. The v1.0 implementation starts with a Python 3.13 FastAPI and aiogram service skeleton.

## Milestone 1 Scope

This repository currently contains only the initial service skeleton, configuration model, development tooling and tests.
